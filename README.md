## 📌 Caso de estudio: Alke Wallet con Django

### Descripción de la actividad

Alke Wallet es una aplicación académica desarrollada durante el módulo 7 para gestionar clientes, cuentas y transacciones. Este proyecto me permitió integrar conocimientos de Python, Django y bases de datos en una aplicación con interfaz web.

### Desafío principal

El principal desafío fue comprender cómo conectar los modelos, las vistas, los formularios y las plantillas para que funcionaran en conjunto.

También tuve que implementar restricciones de acceso y resolver un problema en el buscador de clientes, que inicialmente no mostraba los resultados esperados.

### Solución propuesta

Organicé la información mediante tres modelos relacionados: `Cliente`, `Cuenta` y `Transaccion`. Utilicé formularios para registrar datos y vistas para mostrar listados y detalles, incorporando autenticación y permisos para restringir determinadas acciones.

Para corregir el buscador, revisé el método `get_queryset()` y ajusté la consulta mediante el ORM de Django y objetos `Q`, permitiendo buscar clientes por nombre o correo electrónico.

| Git y GitHub | Control de versiones y publicación del repositorio. |

### Principales aprendizajes

- Comprender el patrón **Modelo–Template–Vista (MTV)**.
- Definir modelos y relaciones entre los datos.
- Utilizar el **ORM de Django** para realizar consultas y filtros.
- Conectar formularios con modelos y vistas.
- Incorporar autenticación y permisos.
- Utilizar protección **CSRF** en formularios POST.
- Revisar el recorrido de la información para identificar y corregir errores.
- Documentar y compartir el proyecto mediante GitHub.
