## Proyectos destacados

### 🏦 Alke Wallet – Django

Aplicación web desarrollada con Django para la gestión de clientes, cuentas y transacciones.

Durante este proyecto trabajé con modelos y relaciones de base de datos, ORM de Django, formularios, vistas, templates, autenticación y control de permisos. También implementé funcionalidades para crear, consultar, editar y gestionar información dentro de la aplicación.

**Tecnologías y conceptos:** Python · Django · ORM · SQLite · HTML · Bootstrap · CRUD · Autenticación · Git · GitHub

🔗 [Ver proyecto en GitHub](https://github.com/ElePeldoza/Entrega_Modulo_7)


### 👥 Gestor de Clientes – Python POO

Sistema de gestión de clientes desarrollado en Python aplicando los principales conceptos de Programación Orientada a Objetos.

El proyecto utiliza clases y objetos para representar distintos tipos de clientes e incorpora encapsulamiento, herencia, polimorfismo, validaciones, manejo de excepciones, archivos CSV y pruebas. También desarrollé un diagrama UML para representar la estructura del sistema.

**Tecnologías y conceptos:** Python · POO · Clases · Herencia · Polimorfismo · Encapsulamiento · Excepciones · CSV · UML · Testing

🔗 [Ver proyecto en GitHub](https://github.com/ElePeldoza/Proyecto_Modulo_4)


### 💳 Billetera Digital – jQuery

Aplicación web de billetera digital desarrollada con HTML, Bootstrap, JavaScript y jQuery.

Permite iniciar sesión, consultar y modificar el saldo, realizar depósitos y transferencias, administrar contactos y revisar los movimientos realizados. Utiliza localStorage para mantener información dentro del navegador e incorpora validaciones y actualización dinámica de la interfaz.

**Tecnologías y conceptos:** HTML · Bootstrap · JavaScript · jQuery · DOM · Eventos · Validaciones · localStorage

🔗 [Ver proyecto en GitHub](https://github.com/ElePeldoza/Billetera-Digital-jQuery)
